Overview

Most open-source reconnaissance utilities either dump raw, unverified URL lists in a terminal or lock meaningful correlation behind expensive third-party API keys and cloud dashboards. KeryxOSINT unifies 750+ username platforms, 340+ email services, telecom routing checks, domain/DNS forensics, and public social media extraction inside a self-hosted workstation backed by a local SQLite evidence vault.

Why KeryxOSINT Stands Out

Built from the ground up to eliminate false positives, expiring evidence links, and vendor lock-in:

01 / Evidence-First Resolution

No Black-Box Merging

Separates raw Observations from verified Relationships, surfacing conflicting locations or mismatched avatars across homonyms instead of silently merging unrelated people.

02 / Visual Forensics

Perceptual dHash & Local Caching

Downloads avatars and public media thumbnails locally and computes 64-bit dHash fingerprints to prove visual identity links across platforms—even when CDN URLs expire.

03 / Zero Paid Dependencies

100% Local Execution

Runs directly on your machine with Python, Flask, and SQLite. No mandatory cloud accounts, telemetry, or commercial API subscriptions required to run full multi-vector sweeps.

04 / Recursive Pivoting

Auto Bio & Caption Harvesting

Extracts exposed emails, @handles, and personal domains from discovered profile bios and feeds them directly into follow-up sweeps with one click.

05 / Noise Filtering

Rate-Limit Isolation

Separates HTTP 403/429 rate-limited endpoints from real 200 OK matches so analysts review verified intelligence rather than scraper errors.

06 / Chain of Custody

SHA-256 Evidence Vault

Persists every investigation locally with cryptographic SHA-256 hashes, Wayback Machine archiving, and instant JSON, CSV, and print-clean PDF exports.
