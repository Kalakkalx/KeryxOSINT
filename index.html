Frequently Asked Questions

What is KeryxOSINT and who developed it?

KeryxOSINT is a local-first open-source intelligence and digital forensics workstation created by Kalakkalx at Hollowboat. It correlates usernames, emails, phone numbers, domains, CVEs, Git commits, and public social media artifacts across 320+ zero-cost modules on your local machine without sending queries to third-party SaaS servers.

How does the optional local LM Studio AI Analyst work?

When you load any local LLM in LM Studio at http://127.0.0.1:1234, KeryxOSINT automatically detects the active model, synthesizes all discovered cards into a 3-paragraph cross-referenced intelligence brief below the About column, and unlocks an interactive follow-up Q&A chat to interrogate the report—while staying 100% offline. If LM Studio is off, KeryxOSINT renders all standard cards normally with zero disruption.

How does KeryxOSINT prevent false positives across common usernames?

Unlike basic username scrapers that treat every HTTP 200 response as the same person, KeryxOSINT caches profile avatars locally, calculates 64-bit dHash visual similarity scores, analyzes 24-hour UTC activity patterns, cross-checks bio metadata, and isolates conflicting accounts until corroborating evidence is found.

What export formats does the local evidence vault support?

Every completed investigation is stored in a local SQLite database with cryptographic SHA-256 hashes and can be exported immediately to structured JSON, CSV, or print-ready PDF forensic reports.
