Overview

KeryxOSINT is an open-source intelligence and digital forensics workstation engineered for explainable, evidence-first identity reconnaissance. Operating 100% locally without mandatory cloud dependencies or paid API subscriptions, it correlates data across 750+ username platforms, 340+ email services, telecom routing records, domain certificates, and public social media.

Core Capabilities

  • Evidence-First Entity Resolution: Separates raw observations from verified relationships and flags contradictions rather than performing opaque black-box merges.
  • Perceptual Image Fingerprinting (dHash): Locally caches avatars and media artifacts to cross-match profile pictures across platforms without relying on expiring CDN URLs.
  • Git & Domain Forensics: Extracts commit author timelines, certificate transparency subdomains, DNS records, and historical web snapshots.
  • Recursive Bio Pivoting: Harvests exposed emails, handles, and external links from discovered bios for follow-up sweeps.
  • SHA-256 Local Evidence Vault: Persists cases in SQLite with cryptographic integrity hashes and instant JSON, CSV, and printable PDF exports.
